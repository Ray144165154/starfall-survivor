# ✦ 星渊幸存者 · Starfall Survivor

一个零依赖、开箱即玩的浏览器肉鸽生存小游戏。驾驶逐星者，在不断升级的星潮中生存五分钟，然后击败星渊守门者。

## 在线游玩

**https://ray144165154.github.io/starfall-survivor/**

## 玩法

- **WASD / 方向键**：移动，武器自动瞄准最近的敌人。
- **空格 / 右下角冲刺按钮**：冲刺，冷却 3 秒，期间免疫伤害。
- **P / Esc**：暂停；离开窗口自动暂停。
- **手机**：在画面上按住并拖动移动，用右下角按钮冲刺。
- 击败敌人掉落紫色星能，靠近自动拾取；粉色补给恢复生命。
- 每次升级随机三选一，也可按 **1 / 2 / 3** 选择。九种进化可以叠加，构筑速射、穿透、多弹道、卫星等流派。
- 五分钟后出现 Boss，击败它即可胜利。死亡后从头开始，纪录保存在本机浏览器中。
- 音效默认关闭，右上角可开启。无需账号、无跟踪、无外部资源。

## 本地运行

需要 Python 3。无需安装依赖：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 http://127.0.0.1:4173 。请通过 HTTP 运行，直接双击 HTML 可能被浏览器的模块安全策略拦截。

## 测试与部署

Node.js 20+：`npm test`。测试覆盖升级上限、随机选项、伤害与无敌状态、经验曲线。

推送到 `main` 后 GitHub Actions 自动运行测试并部署 GitHub Pages；仓库 Settings → Pages → Source 应设置为 **GitHub Actions**。

## 技术

原生 Canvas 2D、ES modules、CSS、Web Audio。全部视觉通过代码绘制，音效实时合成。世界以玩家为中心跟随；敌人、经验与子弹在世界坐标中模拟。后台标签自动暂停，帧间隔有上限。
